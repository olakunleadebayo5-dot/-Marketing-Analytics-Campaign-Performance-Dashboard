# 📊 Marketing Analytics & Campaign Performance Dashboard

## 📌 Project Overview

This project focuses on analysing digital marketing performance across multiple advertising channels, campaigns and data sources using Microsoft Power BI.

The objective is to provide a consolidated view of marketing activities, evaluate campaign effectiveness, monitor advertising expenditure and identify performance trends that can support data-driven marketing decisions.

The project uses synthetic daily marketing data covering January to December 2023.

---

## 🎯 Project Objectives

- Evaluate marketing campaign performance across multiple channels.
- Analyse advertising expenditure and cost efficiency.
- Monitor impressions, clicks, video views and conversions.
- Compare marketing performance across advertising platforms.
- Identify high-performing and underperforming campaigns.
- Track current-period performance against the previous period.
- Develop an interactive dashboard for marketing performance monitoring.

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks eight primary marketing KPIs:

1. Total Advertising Spend
2. Cost Per Mille (CPM)
3. Click-Through Rate (CTR)
4. Cost Per Click (CPC)
5. Total Video Views
6. Total Impressions
7. Total Conversions
8. Conversion Rate

### KPI Calculations

- CTR = Clicks / Impressions
- CPC = Advertising Spend / Clicks
- CPM = (Advertising Spend / Impressions) × 1,000
- Conversion Rate = Conversions / Clicks

All efficiency metrics are calculated using aggregated measures in DAX.

## 📊 Dashboard Features

The Power BI dashboard contains:

### 1. KPI Monitoring

Eight KPI cards display key marketing metrics, accompanied by trend indicators and sparklines.

### 2. Interactive Filters

Users can filter performance by:

- Date
- AdSetID
- DataSource
- Campaign
- Channel

### 3. Channel Performance Analysis

Compares Organic, Paid Search, Paid Social and Programmatic across marketing performance metrics.

### 4. Campaign Performance Analysis

Provides campaign-level comparisons using impressions, CTR, spend and conversions.

### 5. Data Source Performance Analysis

Evaluates performance across advertising platforms and marketing data sources.

### 6. Channel Performance Trend

A monthly time-series visualization tracks impressions across the four marketing channels.

### 7. Period-over-Period Analysis

Red and green indicators show percentage changes between the current and previous comparison periods.

## 🔍 Key Findings

The completed dashboard presents the following overall figures:

- Total advertising spend: approximately $2.03 million.
- Total impressions: approximately 139.30 million.
- Total video views: approximately 49.46 million.
- Total conversions: approximately 88,510.
- Click-through rate: approximately 1.48%.
- Cost per click: approximately $0.99.
- Cost per mille: approximately $14.59.
- Conversion rate: approximately 4.30%.

### Marketing Performance Observations

- Organic contributes substantial impression volume without paid advertising expenditure.
- Paid marketing channels demonstrate different engagement and cost characteristics.
- Campaign-level comparisons provide visibility into differences in marketing effectiveness.
- Period-over-period indicators support the monitoring of changes in performance.

## 💡 Business Recommendations

Based on the dashboard's analytical capabilities, the following actions are recommended:

- Monitor campaign efficiency using CPC, CPM and conversion rate.
- Investigate campaigns with declining engagement or conversion performance.
- Compare advertising platforms before reallocating marketing budgets.
- Monitor organic performance alongside paid marketing activities.
- Use monthly trends to identify changes in channel performance.
- Evaluate campaign objectives when interpreting performance differences.
